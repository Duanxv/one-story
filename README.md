# 一个故事

一个基于 HTML5 的回合制文字冒险卡牌游戏。你扮演《水浒传》中的郓哥，在郓州卖雪梨为生，通过拖拽卡牌处理各种事件，探索多分支剧情与多个结局。

本游戏已使用 Node.js 打包为 **Windows 桌面应用**，并提供安装包，无需浏览器即可直接运行。

---

## 下载与安装

请从发布页面下载最新安装包（文件名示例）：

```
一个故事-Setup-1.0.0.exe
```

双击安装包，按照提示完成安装。安装完成后，可以从开始菜单或桌面快捷方式启动游戏。

> **注意**：安装包为 Windows 平台（64 位），暂不支持 macOS / Linux。

---

## 系统要求

- 操作系统：Windows 10 / 11（64 位）
- 内存：至少 2 GB
- 存储空间：约 200 MB 可用空间
- 无需安装额外运行环境（已内嵌 Node.js 运行时与 Chromium 内核）

---

## 如何开始游戏

1. 安装后启动「一个故事」。
2. 阅读开场介绍，点击关闭。
3. 地图上会出现事件节点，点击节点打开事件面板。
4. 从底部手牌区拖拽卡牌到事件卡槽中。
5. 满足条件后点击「确认」结算事件。
6. 处理完所有想做的事后，点击右下角「下一回合」推进时间。
7. 注意限时事件的倒计时，以及每回合的食物需求。

---

## 游戏玩法

- **回合制**：每回合可处理多个事件，然后进入下一回合。
- **拖拽卡牌**：将手牌拖入事件槽位，部分槽位有特定要求。
- **人物属性**：人物卡拥有智力、武力、魅力，影响事件结果。
- **限时事件**：右上角红色数字为剩余回合，归零后事件消失并可能触发惩罚。
- **纪事**：左侧面板记录所有行动、获得与失去。
- **多结局**：根据选择、属性与事件完成情况，进入不同结局（如「饿死」「恶有恶报」「水浒」「局外人」等）。
